# Nightly v1.3.0：经授权采用上游 IPC v2

2026-10-12，维护者在查看三组实机对照及 1% low 的取舍后，明确批准合并已实测的上游 **v1.3.0-pre.1 / d063395146bfcad8688efe52904541d342f237f0**，并要求 Release 提供 v1.1.10 回退超链接。该具体授权覆盖此前对此候选的暂缓决定；不取消对其他未来更新的审查。

本分支版本为 **v1.3.0**。完整采用的功能基准为 d063395；上游 main 在本次评估时仍为 de74cd7。两者分别记录在 `config/original-project.json`，不能把预发布分支的采用说成 upstream/main 已更新。没有纳入随后 a10df351 的 IPC/Shadow 菜单及语言切换提交。

本次采用完整 IPC v2 四方向主传输、独立上传和长 Lock lease、VB/IB VA allocator，以及静态 VB/IB 按需映射能力。Client 批次默认 C8，保留 C1/C2/C4/C8/C16/C32；静态映射默认关闭。完整 IPC ABI 为 `0x00020004`，Client 与两个 Host 必须配套构建和更新。Reply Slot 未实现；关闭映射开关不会回到旧 IPC 3。

累计生产补丁由精确上游分层源码重建，再融合 Nightly 差异。保留偏色/纹理布局、资源创建失败清理、buffer 边界、日志名称及队列、异步内存采样等本分支修复；五类高频命令继续采用一次整包编码，并遵循新传输的批次提交规则。不会机械恢复旧 IPC 3 的数据环实现，也不恢复已撤回的 v1.1.13 本地绑定引用优化或未采用的 Shader/SetTexture 候选。

默认仍是 x64 Host、GPLALL 后端与已验证 ThinFlex。L4N 2.51.0、用户配置、配套模板/着色器和作者归属按现有来源清单验证；只交付一个全量 ZIP 及校验文件，设置插件直接安装到 `bin/neko/plugins/L4D2BridgePlugin.dll`。

实测比较的是正式 v1.2.3 配套三端与上游 d063395 预发布配套三端，固定其余运行环境。Ryzen 9 9950X3D / RTX 5090 D，3840×2160、8×MSAA、关闭 VSync、不限帧、自然 CPU 调度；固定 `c1m1_hotel` 楼顶回放，以基线/候选、候选/基线、基线/候选顺序测试三对。每轮开灯、关灯各保留 60 秒，共 12 段、222,573 个有效 Host Present 间隔。

| 三轮中位数 | v1.2.3 | 上游候选 | 变化 |
|---|---:|---:|---:|
| 开灯平均 FPS | 295.72 | 301.55 | +1.97% |
| 开灯 1% low | 189.38 | 176.54 | −6.78% |
| 开灯 0.1% low | 128.35 | 134.08 | +4.46% |
| 关灯平均 FPS | 317.73 | 319.36 | +0.51% |
| 关灯 1% low | 182.81 | 169.23 | −7.43% |
| 关灯 0.1% low | 143.61 | 134.12 | −6.61% |

三组配对的开灯和关灯 1% low 均下降。平均 FPS 为平均 Present 间隔的倒数；low 为最慢 ceil(N×比例) 间隔均值的倒数，未将不同轮次帧合并。两版 ≥16.667 ms 与 ≥33.333 ms 的计数均为 0，不能宣称观察到明显长卡顿。0.1% low 保留记录，不单独决定发布。

两版各完成四次连续换图、两次分辨率切换和正常退出，Reset 与交换链返回成功，没有候选独有的 IPC/Reset 失败；单轮地图加载未发现候选变慢。加载测试未消除缓存/顺序影响，不能宣称加载优化。目视覆盖基线 1440p 和候选恢复 4K 两阶段，没有逐一验证全部阶段的画质。

固定回放不含移动战斗或尸潮，不是 30 分钟连续稳定性证明。指标来自 Host Present，不等同于显示器最终显示帧率或输入延迟，也不能与历史不同条件下约 8% 的差距直接相抵。回放记录、初始辅助进程排除、原始 CSV、配置/哈希、独立复算和恢复记录均保存在本地；私人日志、回放和配置不上传。

**本次整合构建与以上上游原版三端并非同一二进制。** 它另外包含 Nightly 修复、新版本和构建标识；不把上游候选测量冒充本次最终整合包的游戏测试。发布前运行累计补丁检查、三端编译、生产 IPC 跨位数/失败路径及相关原生回归、L4N/ThinFlex/全量包校验；准确结果见本次 Release 的构建记录。本次整合包未重复游戏测试，不保证普遍提帧、低帧或长期稳定性改善。

**如果出现 1% low 下降、掉帧或帧数不稳定，请返回使用 [v1.1.10](https://github.com/NPCodex/L4D2_Dxvk_32to64_Bridge-Nightlybuild/releases/tag/v1.1.10-nightly-20261009-3a75b814-r44c3dfa4ec5c-b38052959126.1)。** 退出游戏及所有 Bridge Host 后，成套恢复旧版 Client 和两个 Host，并按 [README](../README.md) 保留个人配置与备份，不混用两个版本的二进制。该旧版实际 Release 与附件已核验存在；回退不代表所有机器上都已证明该版本更快。
