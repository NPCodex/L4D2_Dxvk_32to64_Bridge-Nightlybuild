# 上游 1.2.2 完整同步：稳定性与性能取舍

本分支 v1.2.2 完整同步上游 `de74cd7d5dd546bfd4f03ab451d0565f1fff0107`。维护者在查看本机一轮对照后，已明确批准采用这一 IPC 正确性更新。相对 v1.1.10，本轮平均 FPS 下降约 8%，没有建立明显的 1% low 收益；采用决定并不表示性能结论改变，也不代表长期稳定性已经验证。

## 本机对照

游戏测试使用 `a831bcff1174abb93f0d12db517b06a18f3caa9e` 的 v1.2.1 候选，验证构建为 [38108732058](https://github.com/NPCodex/L4D2_Dxvk_32to64_Bridge-Nightlybuild/actions/runs/38108732058)。它与本次 v1.2.2 使用相同生产补丁，SHA-256 为 `22a7bd685a2e6ed701215e3a5cadad079d1d70053bd9bfc589e3919869324367`。测试保留 GPLALL + x64 Host、两份 DXVK/Bridge 配置及 L4N 配置，基线为 v1.1.10。

| 指标 | 基线 v1.1.10 | 同补丁候选 | 变化 |
|---|---:|---:|---:|
| 开灯平均 FPS | 400.37 | 367.58 | −8.19% |
| 开灯 1% low | 229.18 | 229.65 | +0.21% |
| 开灯 0.1% low | 137.26 | 131.79 | −3.98% |
| 关灯平均 FPS | 450.78 | 414.74 | −8.00% |
| 关灯 1% low | 248.07 | 235.78 | −4.95% |
| 关灯 0.1% low | 148.92 | 143.31 | −3.77% |

官方地图 `c1m1_hotel → c1m2_streets` 的基线/候选耗时为 11.151/10.604 秒；反向为 10.410/10.436 秒。两者均约 10～11 秒，本轮没有复现上游另报的约 20 秒额外加载时间。这里计量的是发出命令至可用玩家探针响应，包含命令传递、探针和日志延迟，也受缓存与测试顺序影响。

每个版本只跑一轮开灯、关灯、再开灯，各约 65 秒；两段开灯只合并段内帧间隔。FPS 来自 Host Present 间隔，low 值是最慢 1%/0.1% 帧间隔均值的倒数，不是最终显示 FPS、输入延迟或 GPU 执行时间。有效采样为 `SyncInterval=0`、`AllowsTearing=1`，使用相同固定机位，游戏与 Host 临时限制到 CPU 0–15；这不是默认调度下的普遍结论，也没有连续前台状态或连续调度轨迹。单轮样本不构成统计显著性或跨地图、长期稳定性证明。

测试已结束，原安装与配置已恢复。私有逐帧数据、SHA-256、进程和安装恢复证据保留在 `results/upstream-122-game/`，不随玩家包分发。没有延长采样寻找更好结果，本版不宣称提高 FPS。

## 合并与兼容

- 导入上游数据环完整预留、消费进度原子发布与等待重查、失败批次中止、请求/回复所有权清理、optimized Lock 指针保留以及大包回绕修复。
- IPC 协议为 3，必须一起更新或回退 `bin/d3d9.dll`、`bin/.l4d2bridge/L4D2Bridge32.exe` 和 `L4D2Bridge64.exe`，不能混用新旧版本。
- 按真实源码三方合并保留 Nightly 偏色/纹理布局、创建失败清理、buffer lock 边界、连续上传复制、Logger 名称所有权、异步内存采样及已接受的队列路径；取消检查先于首次取时钟，同时保留上游双 acquire 所有权交接。未恢复已撤回的本地绑定引用优化。
- 默认 GPLALL 2.6.8-2 和 x64 Host、单一全量 ZIP + SHA256、ThinFlex、Starfelll（@Starfelll）的 L4N 2.51.0、用户配置/shader、配套模板/QC/VMT及直接安装的设置插件保持原有交付要求。安装和回退按 [README](../README.md) 操作。
- 本次完整同步止于上游 `de74cd7`。PR #7 另作可行性评估，未包含在本次生产补丁中。

## 正确性验证与最终重建

补丁对 NVIDIA `9aa74f8`、`5fd30eae` 和构建源 `3a75b814` 的应用检查均通过，所得 Bridge 源码树一致。本地 x86/x64 数据环契约、Device/Module 双向传输、回绕/满载/故障、API 失败所有权及 Nightly 既有回归通过；上述验证构建完成 MSVC 编译、相关原生测试和完整包校验。

本次最终 v1.2.2 包仍须完成其对应 Actions 的编译、测试与附件身份校验。虽然生产补丁相同，版本与构建标识会改变二进制；此前候选的游戏测试不等于对最终重建附件重新实测。最终提交、build ID 与附件 SHA256 以对应构建记录和发布指纹为准；本轮不重复启动游戏。
