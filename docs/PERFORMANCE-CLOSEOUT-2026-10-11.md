# 性能优化统一盘点与收尾

范围为正式 v1.2.3（47f232c）、当前 IPC 3 和已取得的手电场景证据。本次统一审查此前列出的方向，选择一组候选进行一次游戏对照；不把未采用项继续排列成下一轮待办。结论只适用于这些代码与证据，不等于证明未来硬件、场景或上游代码没有优化空间。

| 方向 | 本轮处理 | 依据与边界 |
|---|---|---|
| Shader 常量与 SetTexture 编码 | 已实现，进入合并对照 | 六类常量共用宏与纹理提交使用已有完整 Packet，保留即时提交及上传；旧开灯场景约 2,489 次/帧，占全部设备队列命令约 35%。调用量用于选方向，不是耗时或 FPS 收益。 |
| 其他 Client 命令编码 | 审查完成，本轮不扩展 | Draw/RenderState/Sampler/TextureStage、StreamSource/Indices、Buffer Unlock 已使用完整编码。余下 RenderTarget、深度绑定、Shader 绑定、声明、Viewport/Scissor 等仍有普通发送，但没有独立收益证据；不为覆盖 API 数量机械重写创建、读回、StateBlock 与多 Blob 命令。 |
| Host 设备句柄缓存 | 不采用，结束本轮评估 | 正常哈希命中不分配；没有独立生产耗时证据。缓存会引入创建、销毁、句柄复用与多设备失效规则，无法由命令数量推定值得加入。 |
| Host Surface/Volume 连续复制 | 不采用，结束本轮评估 | 已有稳定手电采样没有纹理上传；紧密复制对该场景没有执行机会。不同 pitch、压缩块、区域及失败路径需要保留，不能直接删循环。Client 连续复制已经存在并保留。 |
| 临时缓冲与分配复用 | 不采用，结束本轮评估 | Volume Lock 需独立拥有存储且未出现在目标采样；Query 约 26 次/帧、开灯没有增加，未定位出分配器瓶颈。池化还增加 x86 保留内存和生命周期管理。 |
| 跨命令批处理 / C32 | 不采用，结束本轮评估 | 旧实验不等于正式 v1.2.3 的收益；整合需改变 IPC 控制与发布时序，现有即时提交候选不引入该实验协议。不能把旧实验的百分比用来抵消另一次 8% 回退。 |
| 等待、唤醒与同步 | 保留现有实现 | 队列就绪路径的多余计时已减少；查询和回复等待未随开灯明显放大。没有证据支持删除同步、忙等或增加在途帧，避免用额外排队换表面 FPS。 |
| 跨核 / CCD 调度 | 不设硬件相关默认 | 测试两包采用同样约束以控制波动；单机表现不能支撑给所有玩家强制绑核、优先级或电源配置。 |
| 编译、链接与断言 | 保留 debugoptimized | 当前已为优化构建。Release/NDEBUG 会把部分 dynamic_cast 变为 static_cast 并裁掉日志能力；LTO 未取得同工具链收益证据。不附带扩大代码生成变化。 |
| 日志与诊断采样 | 保留默认关闭和现有快路径 | 关闭时提前返回，Client 普通采样已异步、禁用日志已避开格式化/分配、Tracy 已关闭。Host 开启监控时仍同步采样，但不能解释默认配置差距；本轮不为诊断模式新增线程生命周期。 |
| 状态去重、引用精简与画质设置 | 不重新引入 | 不恢复 v1.1.13 撤回的引用改动或未证明稳定收益的常量缓存；不减少实际绘制/上传，不降低阴影或手电质量，不替换 GPLALL。 |

补充核对：旧开灯计数中 RenderTarget 约 304、PixelShader 150、VertexShader 93、DepthStencil 91、VertexDeclaration 84、Viewport 59、Scissor 17 次/帧；它们已纳入剩余发送路径审查，没有遗漏为“下次发现”的项目。诊断会扰动帧率，因此不将这些 handler 时间作为可回收的生产耗时。当前选择覆盖调用最密集、共享实现且能保持协议的新增路径；其他潜在改写以证据不足、缺少目标场景执行或风险不匹配作出不采用结论，而非宣称没有理论收益。

本候选原生回归覆盖 2,628 组旧/新编码及独立字节布局、21 组满队列/部分容量故障，以及 x86 Client 对 x86/x64 Host、普通/紧凑数据环的 8,000 条跨进程命令。本机 MinGW 通过，MSVC 和整包验证交由本次候选 Actions；夹具不代替真实 D3D、COM 或游戏验证。生产变更仅两处提交作用域，其余校验、资源状态、Host 解码与默认配置保持原样。

游戏验收只使用本轮新生成的包身份及一轮同场景对照；主指标为平均 FPS、1% low、长帧与实际异常，0.1% low 留作辅助，不独立否决。采样完成后记录结果并决定采用或停止；不重复相同测试寻找有利数字。该文档提交时游戏验证尚未完成，不能宣称补回此前约 8% 差距。详细候选说明见 [SHADER-TEXTURE-PACKETS.md](SHADER-TEXTURE-PACKETS.md)。
