# 45 项优化结案台账

基准：v1.3.0 / `ac75142ae045a53c19b9a950b088fbe27314d3ab`。日期：2026-10-12。

维护者明确要求一次处理全部 45 项，并选定“保留功能、画质与正确性；危险方案用等价改进替代，失败项不发布”。因此，“处理完成”包括实际实现、等价替代、已有能力验收和有依据地关闭；不代表把互斥架构全部叠加，也不把未实现的方案写成已实现。下表固定编号，不再把同一批已关闭方案拆成下一轮待办。新的代码、驱动、工作负载或故障证据才构成重新评估理由。

运行时改动与完整补丁、Client/Host 配套编译和整包验收绑定。局部原生测试、微基准与实际游戏数据分别记录；本文件中的组件成本不是 FPS 承诺。

**2026-10-12 整包验收结论：v1.4.4 / `84aff8b` 未通过性能门槛，未合入正式 main、未发布。** 六轮十二段有效采集中，候选平均 FPS 三个配对均下降；中位数开灯 −2.586%、关灯 −1.969%。1% low 中位数分别 −0.719%/−0.778%，但配对方向不一致；0.1% low 作为佐证保留，不单独阻断。CI 和四组双架构换图/Reset/退出 smoke 通过，不能替代性能验收。未继续 30 分钟稳定性测试。正式版保留 v1.3.0。见[性能门禁报告](../results/optimization45/game/PERFORMANCE-GATE-REPORT.md)。

下表“实现”表示候选分支的代码状态，不代表已采用或已发布；“关闭”决定继续有效。后续文档提交造成的 VERSION 递增也不代表新候选已构建或通过游戏测试。没有独立整包验证的子集不因静态审查推测而获得发布资格。

## A：运行时（12 项）

| 编号 | 最终处理 | 实现或关闭依据 |
|---|---|---|
| A1 上传失败 | 实现 | Host Surface/Volume 显式处理 Lock 失败，验证 payload、尺寸、行距和切片距后才复制；失败仍消费本条传输，避免串包。不再依赖 Release 中消失的 assert。 |
| A2 公共参数与句柄 | 实现 | Shader 常量采用防溢出范围比较；Query 校验 flags/长度，只在 S_OK 返回数据；UpdateTexture 先验空和类型；SharedHeap 传递真实分配长度，检查无效 ID 和越界。 |
| A3 批次与帧时间 | 保留 C8；本轮关闭默认调档 | 对照现有批次与真实跨进程流；更大批次吞吐不等于低延迟，保留六档及强制 flush 边界。游戏对照使用相同 C8，避免混淆参数与代码变化。 |
| A4 编码预留快路 | 等价局部实现 | 去掉编码暂存前缀中不会被复制的无用清零，保留初始化边界、预留、取消与发布检查。没有重写整个 Encoder 或改变 external/inline 所有权。 |
| A5 锁合并 | 关闭，不取消必要同步 | 当前 Device 锁可按已有线程安全模式成为 nop；新的跨层锁合并没有足以证明保持重入和全局顺序的依据。保留并发生产者压力验收作为安全替代。 |
| A6 Reply Slot | 等价修复；不引入 Slot 架构 | FIFO 中其他 UID 的回复不再耗尽本线程的空队列重试次数，短暂让出后重查；保留整体硬超时和失败关闭。按默认重试数验证多个等待者与不消费者。 |
| A7 自旋/信用/块布局 | 关闭架构替换 | 当前 v2 已有进度缓存和批次；本轮压力/回绕测试保留同步边界。没有证据支持改成 committed-prefix 字节环、放松内存序或全程忙等。 |
| A8 上传池碎片与扫描 | 实现 | 维护生产者本地空闲页数量与最低空闲位置，保持原 first-fit 选择和有界预算。测试随机碎片、长 pin、迁移和回收；不能把“总空闲足够”当作连续区保证。 |
| A9 Host 设备缓存 | 实验后关闭 | 单设备查表微基准改善，但多设备交替仍有可复现额外成本；不发布缓存。保留不插入空条目的安全查表。 |
| A10 资源表/codec 架构 | 采用边界加固，关闭全面重写 | 本轮落实相关句柄、分配长度和上传边界；不把稠密表、generation 全表、生成式 codec 或分派重排称为已实现。没有真实热点证据支持扩大协议改写。 |
| A11 Host 紧密上传 | 实现 | 严格满足源/目标行距与切片布局时整块复制；其他合法布局逐行复制。修复 x86/x64 最小行宽差异对小 mip 的影响，保留压缩格式专用规则。 |
| A12 暂存复用 | Query 实现；Volume 池关闭 | Host Query 使用有界小缓冲，避免每次轮询堆分配；S_FALSE 不泄漏数据。Client Volume 保持每个未完成 Lock 独占存储，避免额外长期占用 x86 内存。 |

## B：内存、加载与恢复（9 项）

| 编号 | 最终处理 | 实现或关闭依据 |
|---|---|---|
| B1 静态 VB/IB 映射 | 保留并验收现有能力 | 默认关闭，有界 LRU/冷映射成本仍存在。新增菜单便于明确选择，必须重启；不以节省 VA 冒充省提交内存或提帧。 |
| B2 PageBlock/retention/GC | 保留安全策略并回归 | 不扩大不受支持的资源回收，不默认加大 keep/drop；保留历史字节、恢复校验和 GC 预算。已有生产契约验收，不再重复列为未做能力。 |
| B3 ordered completion ACK | 关闭替换 | 保留现有确认；CPU 消费序号不能替代 GPU/恢复完成。无证据表明临时确认对象是本场景瓶颈，不发布未证实的同步替换。 |
| B4 读回结果池 | 关闭新池化 | 超时后的写入者和代际复用会扩大失效范围；保留现有读回隔离、尺寸校验与超时回归。没有以不明生命周期换取缓存。 |
| B5 Host 纹理对象池 | 关闭 | 会保留显存/系统资源并增加 Reset、绑定、子资源生命周期复杂度；当前无重复创建瓶颈证据。现有创建失败清理和换图验收作为安全保障。 |
| B6 纹理内容去重 | 关闭 | 部分更新、内容身份和 hash 成本未建立净收益；不根据尺寸或局部字节错误复用内容。 |
| B7 DXVK mem1 小块 | 关闭默认替换 | 历史其他显卡的内存记录不能证明本机综合改善；维持固定 GPLALL 包及来源校验。 |
| B8 通用零拷贝 | 保留独立 lease，关闭无历史副本方案 | lease 不是通用零拷贝；静态/部分更新仍保留 FULL_SHADOW。本轮 A8 优化分配与 A11 连续复制作为安全等价改进。 |
| B9 学习数据库 | 实现 | 以 string_view、固定字段数组和 checked from_chars 解析，减少字符串/stream/vector 分配；继续持锁全量校验、跨进程可见、校验和及 FlushFileBuffers。 |
