# v1.5.0：上游 main 与 45 项改进整合

维护者于 2026-10-12 在查看候选性能对照后明确要求发布本次组合，并提供 v1.1.10 回退链接。上游生产源码基准为 f6a059b（v1.3.0），本地改进基于 45 项候选 84aff8b；原始性能拒绝记录保留为历史，这次采用不宣称性能门槛已经自动转为通过。

## 实际范围

- 上游 Steam 输入钩子链、鼠标捕获、查询链、Host 子窗口适配和限定工坊可用性代理。默认配置采用上游完整修复片段，启用 presenterWindow 依赖；未知 GameUI/Renderer 版本按上游保护保持原行为。
- 45 项中已实现的上传/Query/公共参数/SharedHeap 边界、并发回复和关闭尾包修复；上传池提示、紧密复制与数据库解析；IPC/静态映射设置和本会话语言菜单。
- 保留偏色/纹理布局、ThinFlex、GPLALL、x64、完整内容历史、同步保护、默认 C8、映射关闭及全部包归属。已关闭或危险方案没有重新引入。
- 单一 68 文件玩家包及 SHA256；原有 L4N 配置、shader、模板、QC/VMT 与直接安装的设置插件保留。上游多包工作流和普通 DXVK 不覆盖本分支发行方式。

## 证据和限制

45 项 v1.4.4 相对 v1.3.0 的三组有效对照：平均 FPS 开灯/关灯 −2.586%/−1.969%，1% low −0.719%/−0.778%，0.1% low −5.763%/−6.856%。这是 Host Present 提交间隔口径；没有 >=16.667 ms 间隔，不能描述为已经测到明显长卡顿。此前四组 x86/x64 换图、Reset、退出通过；没有完成 30 分钟稳定性。

以上不是新增 Steam/Presenter 配置下的最终 v1.5.0 实测。当前源码通过与否由本次原生回归、三端重建与精确源码收据单独核验；发布时保留这一边界。工坊代理开启后仍需有界观察与状态发布，即使 steamWebDiagnostics=False 也不是零观察成本。上游用户兼容反馈不构成所有 Steam/ReShade/Mod 组合的保证。

完整源码合并、验证和发布凭证保存在维护者本地 `results/upstream45-release/`；Release 附对应 CI 链接，不将私有游戏日志/转储加入玩家包。

**如果出现 1% low 下降、掉帧或帧数不稳定，请返回使用 [v1.1.10](https://github.com/NPCodex/L4D2_Dxvk_32to64_Bridge-Nightlybuild/releases/tag/v1.1.10-nightly-20261009-3a75b814-r44c3dfa4ec5c-b38052959126.1)。** 退出游戏和全部 Host 后成套恢复 Client 与两个 Host；安装见 [README](../README.md)。
