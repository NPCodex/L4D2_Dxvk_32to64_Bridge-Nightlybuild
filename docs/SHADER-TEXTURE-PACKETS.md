# Shader 常量和纹理绑定的完整命令编码

本候选以正式 v1.2.3 / `47f232c` 为基线，优化 Client 的 `SetShaderConst` 发送宏（覆盖 Vertex/Pixel 的 F/I/B 六类常量）与 `SetTexture` 最终发送作用域。已有 `bridge_data::payload` 和 `fields` 构造一次预留 UID、字段及载荷；Host 按原有格式消费。

所有常量上传继续执行，原始浮点字节保持原样。原有参数/范围检查、状态记录、dirty 标记、COM 引用、纹理类型、解绑、锁、可选回复、错误转换和即时提交均保留。此项没有启用常量缓存、同值调用过滤、跨 API 批处理或新的协议、后端、默认配置。

测试从生产源码提取新提交作用域和原 Host 读路径，复用真实 Command、共享内存及 serializer。需检查旧编码等价、UID/flags、原始浮点位、零长/空载荷、寄存器上限、环尾回绕、满队列失败及故障后停止，并验证 x86 Client 对 x86/x64 Host 的实际跨进程传输。传输夹具不代替真实 D3D9 参数校验、COM/stateblock 行为或 GPU 测试。

当前候选尚未完成游戏评估。计划使用精确包哈希的一轮 v1.2.3 对照，以平均帧、1% low 和实际卡顿为主要参考，0.1% low 保留为辅助记录。此前 v1.2.3 的成绩与传输微基准不代表本次收益；不追加相同测试寻找有利结果。
